Library Management System

A C++ based Library Management System designed to manage books, members, and borrowing records using object-oriented programming.

Features

- Add new books
- Add library members
- Issue books to members
- Return issued books
- Search books by title
- Search books by author
- Display all books with their availability status
- Uses C++ classes and objects

Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Standard Template Library (STL)

How It Works

The application provides a menu-driven interface. Users can add books and members, issue and return books, search for books by title or author, and view all available library books.

Expected Outcome

The system provides a simple and functional way to manage library operations, including book addition, issuing, returning, and searching.
